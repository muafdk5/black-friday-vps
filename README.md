## 黑五这一个月，什么时候下单不亏

11 月 11 日双十一、11 月 27 日黑五、11 月 30 日网一，中间隔着两周多的空档。限量特价通常几小时就卖完，补货要看运气，商家也很少提前公布具体放量。这意味着两件事：等，不一定等得到更低价；等到手，也不一定是你要的那条线路。

## 线路名称到底指什么，Akile 又标了哪几条

买之前先认清这几个缩写，销售页写得含糊时，你才知道自己缺什么信息。

- **CN2 GIA**：电信精品网 AS4809，去程回程都走 CN2，延迟低、晚高峰稳，价格最高。
- **CN2 GT**：出国段走 CN2，国内段走普通 163 骨干，晚高峰稳定性差一截。
- **CN2**：商家只写 CN2、没说明 GIA 还是 GT，按 GT 的水平预期更稳妥。
- **9929**：联通精品网 AS9929（CUII），联通用户效果最好。
- **4837**：联通普通骨干，带宽便宜量大，晚高峰可能拥堵。
- **CMIN2**：移动精品网 AS58807，移动用户效果最好；**CMI** 是移动国际普通出口 AS58453，比 CMIN2 弱一档。
- **三网优化**：商家写明电信、联通、移动三家回程都走优化线路。

Akile 官方只笼统写了“包含 CN2、9929、CMI、SoftBank 等优化线路”，没有逐套餐标明哪一档走哪条。日本系列的商品说明写的是“包含直连和路由调优型号”，也没说哪个型号对哪个。同样的问题出现在价格上：JPPro 系列比 JPHyper 贵，带宽和流量反而更少；洛杉矶的 LAXPro 比 LAXLite 贵出好几倍，带宽只有 300 到 500Mbps，官方资料没有说明两者网络上的差别。

所以看中某一档，先去下单页把线路说明读一遍，再决定。读不到明确标注时，把它当普通国际线路来预期，别按 CN2 GIA 的效果做规划。

## 按用途挑：四种买法，和三种没必要

**只要一台能跑的机器：¥8.88 那档就够。**
跑监控探针、定时脚本、Telegram bot、小型静态站，1 核 1GB 加 1TB 流量绰绰有余。这一档还给 5Gbps 端口，纯粹是余量。SGLite-One 贵 ¥1.54，换的是新加坡节点，需要东南亚出口再考虑。

**国内访问要顺：优先看香港，但别指望它跑 Claude Code。**
香港、澳门、日本离得近，SSH 和网页响应天然比美西舒服。这里有一条很多人会忽略的限制：香港机房不在 Anthropic 的支持地区内，用它跑 Claude Code 会卡在地区校验上，选机房时得避开。要跑这类工具，去美西或日本。

**要日本节点和流媒体解锁：JPHyper-Lite 比 JPPro 划算。**
官方说日本机房支持当地流媒体解锁。同样 1 核，JPHyper-Lite 给 2GB 内存、1TB 流量、2.5Gbps 端口，只收 ¥14.99；JPIIJ-Lite ¥24.99 是 1GB 内存、1Gbps。除非你明确要 IIJ 这条线路，否则按配置和价格选，JPHyper 更合算。

**大流量中转、多人共用：按流量选香港档。**
HKLite-Standard 的 10TB 和 HKLite-Pro 的 30TB 才是给团队、多设备、跑几 TB 月流量的场景准备的。一个人用，Pro 多出来的 20TB 流量基本浪费，¥237.49 的月付不如拿去买两台 Mini 分开放。

## 算清真实成本：退款、换 IP、续费

**退款规则在两份整理里对不上，这是最需要你自己确认的一项。** 一份写的是新购 3 天内退 80%、3 到 7 天退 50%、7 到 10 天退 20%、超过 10 天不退，而且删机后的退款进入账户余额，不原路退回；另一份整理写“特价机器方案不受理任何退款”。哪条适用于你看中的套餐，只能以下单时的条款为准。年付之前，这一步别跳过。

**换 IP 是要花钱的。** 第三方整理给出的口径是：控制面板自助更换 ¥35 一次，走工单更换是 1500 AK 币一次。做需要干净 IP 的业务，这笔成本要算进年度预算。

**年付不一定更便宜。** LAXLite-One 的第三方标价是 ¥8.88/月起、年付 ¥106.56，正好等于月付价乘 12，也就是说这台机器年付没有任何折扣。其他档位是否如此，要看下单页的计费周期。为“年付更划算”提前锁定一年，在 Akile 这里不一定成立。

**别把优惠码算进预算。** 网上流传的 Akile 优惠码页自己前后矛盾：前面写有一个 8 折码用于轻量云，后面又写“目前 AkileCloud 没有有效的优惠码”。同一个订单只能填一个码，特价套餐通常也不能叠加。按原价做预算，能省是意外。

## 下单前最后确认

1. 下单页的线路说明写了什么。只写“优化线路”没写具体走哪张网的，按普通线路预期。
2. 退款条款是否覆盖你看中的套餐，特价机是否例外。
3. 流量是单向还是双向计费，用尽后是停机还是限速。
4. 每账户限购几台，续费价和首单价是否一致。
5. 用途和机房是否匹配，跑 Claude Code 这类工具要避开香港。

按你的情况对号：

- 只跑脚本、探针、小博客 → LAXLite-One，¥8.88 起，别加钱。
- 国内访问要顺、能接受 1 核 1GB → HKLite-Mini ¥24.99，或日本 JPHyper-Lite ¥14.99。
- 要日本流媒体解锁 → JPHyper-Lite 优先，明确要 IIJ 线路再上 JPIIJ 系列。
- 多人共用、每月几 TB → 香港 HKLite-Standard 的 10TB 起步。
- 需要干净 IP 做业务 → 先把 ¥35 一次的换 IP 成本算进预算，再决定买哪档。
